The line:

> My phone updates itself at 3am, restarts, then asks if I enjoyed the update — as if it didn't just eat my alarm.

`main.py` validates the line (1–200 characters, exactly one line, not blank) and writes it to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`).
